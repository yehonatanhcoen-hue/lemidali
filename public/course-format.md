# פורמט קובץ קורס — לומדה (Lemidali)

מסמך זה מסביר איך לבנות קובץ קורס שאפשר לייבא לאפליקציית "לומדה".
הוא נכתב כך שאפשר להדביק אותו כמו שהוא בכל צ'אט AI, יחד עם חומרי הקורס (סילבוס, רשימת סרטונים, סיכומים), ולבקש ממנו להפיק את הקובץ.

---

## 1. תמונה כללית

קובץ אחד = קורס אחד, בפורמט **JSON**.

```
קורס
└── נושאים (topics)            ← לפי הסדר
    ├── שיעורים (lessons)        ← לפי הסדר
    │   ├── חומרי לימוד (materials) — סרטונים, מאמרים, PDF, קישורים
    │   └── מבחן שיעור (quiz)     — אופציונלי
    └── מבחן סיכום נושא (final_exam) — אופציונלי
```

הסדר במערכים הוא סדר הלימוד באפליקציה.

**נעילה לפי ציון:** כשהאפשרות פעילה (ברירת מחדל), אי אפשר לפתוח שיעור או מבחן סיכום לפני שעוברים את כל המבחנים שלפניהם בציון העובר. שיעור בלי מבחן לא נועל כלום. לכן כדאי שלכל שיעור משמעותי יהיה מבחן.

## 2. השדות

### קורס (שורש הקובץ)

| שדה | חובה | סוג | הסבר |
|---|---|---|---|
| `format` | ✔ | `"lemidali-course"` | תמיד הערך הזה בדיוק |
| `version` | ✔ | `1` | תמיד 1 |
| `key` | ✔ | key | מזהה הקורס |
| `title` | ✔ | טקסט | שם הקורס |
| `description` | | טקסט | |
| `passing_score` | | 0–100 | ציון עובר ברירת מחדל לכל המבחנים. ברירת מחדל: 80 |
| `lock_until_passed` | | true/false | נעילה לפי ציון. ברירת מחדל: true |
| `topics` | ✔ | מערך נושאים | לפחות נושא אחד |

### נושא (topic)

| שדה | חובה | הסבר |
|---|---|---|
| `key` | ✔ | |
| `title` | ✔ | |
| `description` | | |
| `lessons` | ✔ | מערך שיעורים, לפחות אחד |
| `final_exam` | | מבחן סיכום לנושא: `{ "title"?, "passing_score"?, "questions": [...] }` |

### שיעור (lesson)

| שדה | חובה | הסבר |
|---|---|---|
| `key` | ✔ | |
| `title` | ✔ | |
| `description` | | מה לומדים בשיעור, משפט או שניים |
| `duration_minutes` | | משך מתוכנן בדקות (מספר שלם). ברירת מחדל: 60 |
| `materials` | | מערך חומרי לימוד |
| `quiz` | | `{ "passing_score"?, "questions": [...] }` |

### חומר לימוד (material)

| שדה | חובה | הסבר |
|---|---|---|
| `type` | ✔ | אחד מ: `video`, `article`, `pdf`, `document`, `link` |
| `title` | ✔ | כותרת קצרה, למשל "הרצאה 3 – חלק א׳" |
| `url` | ✔ | כתובת מלאה שמתחילה ב-`https://` |
| `key` | | מומלץ. אם חסר, המזהה נגזר מה-URL |
| `duration_minutes` | | אורך הסרטון/זמן קריאה |
| `note` | | הערה קצרה, למשל "לצפות מדקה 12" |

סרטוני YouTube (`youtube.com/watch?v=…` או `youtu.be/…`) עם `type: "video"` מוצגים עם תמונה ונגן בתוך האפליקציה.

### שאלה (question) — ארבעה סוגים

שדות משותפים לכל הסוגים:

| שדה | חובה | הסבר |
|---|---|---|
| `key` | ✔ | |
| `type` | ✔ | `single` / `multiple` / `true_false` / `open` |
| `question` | ✔ | נוסח השאלה |
| `explanation` | | למה זו התשובה הנכונה. מוצג אחרי שעונים — מומלץ מאוד |
| `points` | | משקל השאלה בציון, 1–10. ברירת מחדל: 1 |

**`single` — בחירה אחת נכונה**
```json
{ "key": "l1-q1", "type": "single", "question": "...?",
  "options": ["א", "ב", "ג", "ד"], "correct": 2,
  "explanation": "..." }
```
`options`: 2–6 תשובות. `correct`: **האינדקס** של התשובה הנכונה, **מתחיל מ-0** (בדוגמה: "ג").

**`multiple` — כמה תשובות נכונות ("סמן את כל הנכונות")**
```json
{ "key": "l1-q2", "type": "multiple", "question": "...?",
  "options": ["א", "ב", "ג", "ד"], "correct": [0, 3] }
```
`options`: 2–8. `correct`: מערך אינדקסים (מ-0), לפחות אחד. התשובה נחשבת נכונה רק אם סומנו בדיוק כל הנכונות.

**`true_false` — נכון / לא נכון**
```json
{ "key": "l1-q3", "type": "true_false", "question": "טענה.", "correct": false }
```

**`open` — שאלה פתוחה**
```json
{ "key": "l1-q4", "type": "open", "question": "הסבר במילים שלך...",
  "model_answer": "תשובה טובה מזכירה ש..." }
```
הלומד כותב תשובה, רואה את `model_answer` ומסמן בעצמו אם צדק. כדאי ש-`model_answer` יפרט את הנקודות שחייבות להופיע.

## 3. כללים חשובים

1. **`key`**: אותיות אנגליות קטנות, ספרות ומקפים בלבד (`lesson-3`, `t2-exam-q4`). עד 64 תווים. **כל key ייחודי בכל הקובץ.**
2. **לא לשנות key אחרי ייבוא.** ההתקדמות, הציונים והסיכומים מקושרים אליו. מותר לשנות כותרות, סדר, שאלות ותוכן — ההתקדמות נשמרת. key שהשתנה = פריט חדש, וההתקדמות של הישן נמחקת.
3. אינדקסים ב-`correct` **מתחילים מ-0**, וחייבים להיות בטווח של `options`.
4. **אין להמציא כתובות URL.** משתמשים רק בקישורים שסופקו. אם חסר קישור, משמיטים את החומר ומציינים זאת ברשימת "פערים" אחרי ה-JSON.
5. JSON תקני: מירכאות כפולות, בלי הערות, בלי פסיק אחרי האיבר האחרון.
6. השאלות צריכות לבדוק הבנה של חומר השיעור, לא זיכרון של פרטים שוליים. מסיחים (תשובות שגויות) סבירים ובאורך דומה לתשובה הנכונה, ומיקום התשובה הנכונה משתנה בין שאלות.
7. מבחן שיעור: 3–8 שאלות. מבחן סיכום נושא: 5–15 שאלות שמכסות את כל שיעורי הנושא.
8. טקסטים בשפת הקורס (עברית בסדר גמור). שמות שדות תמיד באנגלית כמו בטבלאות.

## 4. ייבוא חוזר ועדכונים

- ייבוא קובץ עם אותו `key` של קורס **מעדכן** את הקורס הקיים.
- פריטים שהוסרו מהקובץ **נמחקים** מהאפליקציה (כולל ההתקדמות שלהם). לפני הייבוא מוצגת תצוגה מקדימה שמפרטת מה ייווסף, יעודכן וימחק.
- לכן הקובץ הוא "מקור האמת" של הקורס. אם ערכת משהו ידנית באפליקציה, ייצא קודם את הקורס (ניהול ← ייצוא) ועבוד על הקובץ המיוצא.
- קורס גדול: אפשר לבקש מהצ'אט נושא אחד בכל פעם, ובסוף לבקש לאחד הכל לקובץ אחד. הקובץ המיובא חייב להכיל את כל הקורס.

## 5. דוגמה מלאה

קובץ דוגמה מלא עם כל סוגי השאלות נמצא באפליקציה: **ניהול ← הורד תבנית**, או בקובץ `public/course-template.json` בפרויקט. JSON Schema לבדיקה אוטומטית: `public/course.schema.json`.

דוגמה מקוצרת:

```json
{
  "format": "lemidali-course",
  "version": 1,
  "key": "my-course",
  "title": "שם הקורס",
  "passing_score": 80,
  "lock_until_passed": true,
  "topics": [
    {
      "key": "intro",
      "title": "מבוא",
      "lessons": [
        {
          "key": "intro-1",
          "title": "שיעור ראשון",
          "duration_minutes": 45,
          "materials": [
            { "key": "intro-1-video", "type": "video", "title": "הרצאה",
              "url": "https://www.youtube.com/watch?v=XXXXXXXXXXX", "duration_minutes": 20 }
          ],
          "quiz": {
            "questions": [
              { "key": "intro-1-q1", "type": "single", "question": "...?",
                "options": ["...", "...", "...", "..."], "correct": 1,
                "explanation": "..." }
            ]
          }
        }
      ],
      "final_exam": {
        "questions": [
          { "key": "intro-exam-q1", "type": "true_false", "question": "...", "correct": true }
        ]
      }
    }
  ]
}
```

## 6. בדיקה לפני מסירה (לצ'אט שמפיק את הקובץ)

- [ ] `format` = `"lemidali-course"`, `version` = `1`
- [ ] לכל נושא, שיעור ושאלה יש `key` תקין, וכל ה-keys שונים זה מזה
- [ ] לכל `single`/`multiple` יש `options` ו-`correct` בטווח (מ-0)
- [ ] לכל `true_false` יש `correct` בוליאני, לכל `open` יש `model_answer`
- [ ] כל `url` מתחיל ב-`https://` ונלקח מהחומר שסופק — לא הומצא
- [ ] `duration_minutes` מספרים שלמים
- [ ] JSON תקני בלבד

## 7. פרומפט מוכן

להדביק בצ'אט חדש, אחרי המסמך הזה:

> לפי המסמך "פורמט קובץ קורס — לומדה" שלמעלה, בנה קובץ קורס מתוך החומר שאצרף.
> - חלק לנושאים ושיעורים לפי הסילבוס. כשאין חלוקה ברורה, הצע חלוקה הגיונית של שיעורים באורך 30–90 דקות.
> - שבץ כל קישור כ-material בשיעור המתאים, עם type, title ו-duration_minutes אם ידוע. אל תמציא קישורים.
> - לכל שיעור כתוב מבחן של 3–8 שאלות בשילוב סוגים (בעיקר single ו-multiple, מעט true_false ו-open), עם explanation לכל שאלה.
> - לכל נושא כתוב final_exam של 5–15 שאלות שמכסות את כל שיעוריו.
> - passing_score: 80, lock_until_passed: true.
> - החזר בלוק ```json אחד עם הקובץ המלא. אחריו, אם יש, רשימה קצרה של פערים (קישורים חסרים, נושאים לא ברורים).
>
